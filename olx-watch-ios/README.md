# OLX Watch — iPhone

Личное приложение: лента новых объявлений OLX.kz по вашим поискам и пуш на каждое новое.
Данные — с сервера `olx-watch-server/` на kliko.kz. Выпускается с аккаунта разработчика
Kliko через TestFlight, bundle id `kz.kliko.olxwatch`.

- **Лента** — новые сверху: фото, цена, город, «N минут назад», пометки «⚡ раньше поиска»,
  «на проверке», «магазин». Тап — объявление в приложении OLX (или Safari); свайп —
  все объявления автора; долгое нажатие — поделиться, скопировать, параметры.
- **Поиски** — добавить ссылкой с olx.kz, пауза, удалить.
- **Настройки** — адрес сервера и ключ, турбо вкл/выкл, статистика, пробный пуш.
- **Пуш** на каждое новое объявление; тап открывает объявление сразу.

## Сборка и установка

1. Один раз: App Store Connect → Apps → «+» → New App, bundle id `kz.kliko.olxwatch`
   (если его нет в списке — сначала запустить сборку без заливки, она заведёт App ID).
2. GitHub → Actions → «OLX Watch · TestFlight» → Run workflow, `upload = true`.
3. Через 10–30 минут сборка появится в TestFlight на iPhone (приложение TestFlight,
   тот же Apple ID, что в команде).

Пуш в репозиторий, меняющий `olx-watch-ios/`, запускает сборку без заливки — проверку,
что всё компилируется и подписывается.

Код: `Sources/API.swift` (сервер), `AppModel.swift` (состояние, пуши, Связка ключей),
`Views.swift` (экраны), `OLXWatchApp.swift` (запуск и обработка пушей).
