# OLX Watch — iPhone

Личное приложение: лента новых объявлений OLX.kz по вашим поискам и уведомление на каждое новое.
**Проверки идут прямо с телефона** — как обычный просмотр сайта; сервер не нужен (с хостинга
kliko.kz OLX отвечал 403). Поиски и лента хранятся в телефоне. Выпускается с аккаунта
разработчика Kliko через TestFlight, bundle id `kz.kliko.olxwatch`.

- Пока приложение на экране: поиск раз в 30 сек, турбо (5 следующих номеров) раз в 10 сек.
- В фоне: iOS изредка будит приложение проверить поиски (обычно раз в 15+ минут) — без турбо.
- На 403/429 от OLX — пауза, с каждым разом дольше (до 15 минут); обходов нет.

- **Лента** — новые сверху: фото, цена, город, «N минут назад», пометки «⚡ раньше поиска»,
  «на проверке», «магазин». Тап — объявление в приложении OLX (или Safari); свайп —
  все объявления автора; долгое нажатие — поделиться, скопировать, параметры.
- **Поиски** — «+»: рубрика (подрубрики — с самого OLX), город, слова, цена; или ссылка с olx.kz.
- **Настройки** — турбо вкл/выкл, статистика (проверено номеров, найдено), «проверить сейчас».
- **Уведомление** на каждое новое объявление; тап открывает объявление сразу.

## Сборка и установка

1. Один раз: App Store Connect → Apps → «+» → New App, bundle id `kz.kliko.olxwatch`
   (если его нет в списке — сначала запустить сборку без заливки, она заведёт App ID).
2. GitHub → Actions → «OLX Watch · TestFlight» → Run workflow, `upload = true`.
3. Через 10–30 минут сборка появится в TestFlight на iPhone (приложение TestFlight,
   тот же Apple ID, что в команде).

Пуш в репозиторий, меняющий `olx-watch-ios/`, запускает сборку без заливки — проверку,
что всё компилируется и подписывается.

Код: `OLX.swift` (номера, поиск, карточка, фильтры, рубрики), `AppModel.swift` (сборщик,
хранение, уведомления, фон), `Models.swift`, `Views.swift` (экраны), `OLXWatchApp.swift`.
