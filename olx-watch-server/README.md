# OLX Watch — сервер (PHP, хостинг kliko.kz)

Сборщик новых объявлений OLX.kz для iPhone-приложения OLX Watch (`olx-watch-ios/`).
То же, что телеграм-бот `olx-watcher/`, только на PHP и с пушами на iPhone.

- **Поиск** — ваши ссылки поиска OLX, «сначала новые», раз в 30 сек.
- **Турбо** — следующие номера объявлений напрямую, раз в 5 сек: объявление ловится
  до того, как попадёт в поиск (в том числе на проверке). Короткий код в ссылке —
  номер в 62-ричной записи: `IDr9sfK` = 401214632.
- Новое → в ленту приложения и пушем на iPhone (APNs, тот же ключ .p8, что у Kliko).

## Установка

1. Залить папку на хостинг, например в `kliko.kz/olx-watch/` (файлы: `api.php`, `lib.php`,
   `watch.php`, `cron.php`, `.htaccess`, `config.sample.php`). Снаружи открыт только
   `api.php` — остальное закрывает `.htaccess`.
2. `config.sample.php` → `config.php`, заполнить:
   - `api_token` — длинная случайная строка (её же вводите в приложении);
   - `apns_key_p8`, `apns_key_id`, `apns_team_id` — те же, что `APNS_*` в `admin_config.php`
     Kliko; `apns_bundle_id` оставить `kz.kliko.olxwatch`;
   - `db_file` — лучше вне веб-корня.
3. Cron в панели хостинга, раз в минуту:
   ```
   * * * * * php /полный/путь/olx-watch/cron.php
   ```
   Скрипт живёт ~55 секунд и сам крутит поиск и турбо внутри; замок не даёт двум
   запускам работать одновременно.
4. В приложении: Настройки → адрес `https://kliko.kz/olx-watch/api.php` и ключ `api_token`.

Нужны PHP 8.1+, расширения `pdo_sqlite`, `curl` (с HTTP/2 — как для пушей Kliko), `openssl`.

## Проверка

```bash
php tests/run.php     # без сети: номера, разбор, фильтры, поиск+турбо+пуш, подпись APNs
```

Устройство OLX.kz изнутри из среды разработки проверить не удалось (сайт был недоступен).
Если в приложении «Сборщик работает», но лента пустая, а у поиска ошибка — пришлите её
текст (или вывод `php -r 'require "lib.php"; var_dump(fetch_search("ССЫЛКА"));'` на
хостинге): поправлю разбор под то, что реально отдаёт OLX.

## Риски

- Правила OLX запрещают автоматический сбор данных. Запросы идут с адреса хостинга
  kliko.kz: при 403/429 сборщик сам уходит на паузу (до 15 мин). Сайту Kliko блокировка
  со стороны OLX не мешает — он к OLX не обращается.
- Турбо — ~2 запроса в секунду. Если OLX начнёт ограничивать — выключите турбо в приложении.
