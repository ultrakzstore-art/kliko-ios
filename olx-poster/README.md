# OLX Poster

Приложение для Windows: фотографируешь товар, Claude по фото пишет объявление, а приложение
само подаёт его на OLX.kz — одно раз в 5 минут, 10 часов в день. Без ручного ввода.

Эксперимент на рынке OLX, к Kliko не относится. Живёт здесь временно, пока нет отдельного
репозитория.

## Как это работает

```
фото ─┬─ страница для телефона (QR-код)
      ├─ папка-входящие (OneDrive / Google Диск / USB)      ──►  очередь
      └─ перетащить в окно

очередь ──► Claude смотрит фото → заголовок, описание, рубрика, цена, параметры   (сразу)
        ──► робот открывает форму OLX во встроенном браузере и заполняет её      (раз в 5 мин)
```

- **Окно**: слева — очередь и настройки, справа — OLX.kz. Вход в аккаунт OLX делаешь сам,
  один раз: сессия сохраняется между запусками.
- **Черновик** (`src/describe.js`): один запрос к Claude с фото и схемой ответа. Бренд и
  размер читаются с бирок; если чего-то не видно — пишет предупреждение, а не выдумывает.
- **Подача** (`src/poster.js`, `src/page-tools.js`): Claude видит список полей страницы
  (при необходимости — скриншот) и действует настоящими кликами и вводом с клавиатуры.
  Устройство формы OLX в код не зашито — оно меняется. Вместо этого робот записывает себе
  заметки о том, что сработало (Настройки → «Что робот запомнил»), и со временем подаёт
  быстрее.
- **Ограничения робота**: не платит и не берёт «Топ»/VIP; не вводит пароли, SMS-коды и
  капчи. В таких случаях расписание встаёт на паузу, приходит уведомление Windows, а
  товар помечается «нужны вы».

## Установка

1. Скачать установщик: GitHub → Actions → «OLX Poster · Windows» → последний зелёный
   прогон → артефакт **OLX-Poster-Setup**. Windows предупредит о неизвестном издателе:
   «Подробнее» → «Выполнить в любом случае».
2. Ключ Claude API: [console.anthropic.com](https://console.anthropic.com) → API Keys →
   вставить в Настройки. Ключ хранится зашифрованным средствами Windows.
3. В правой части окна войти в свой аккаунт OLX.
4. Настройки: город/район, при желании правила цены и текста.
5. Нажать **▶ Запустить**. Окно можно держать за другими, но не сворачивать: свёрнутому
   окну Windows не отдаёт картинку, и робот «слепнет».

### Фото с телефона

Вкладка «Телефон» → отсканировать QR-код (телефон и ПК в одной Wi-Fi сети). На странице:
«Снять фото» (до 8 штук на товар) → по желанию подсказка и цена → «Отправить в очередь».
При первом запуске Windows спросит про доступ к сети — разрешить для частных сетей.

### Через папку

Папка по умолчанию — `Изображения\OLX`. **Подпапка = один товар**, её имя — подсказка и
цена: `кроссовки nike 42 — 15000`. Свободные фото прямо в папке группируются по времени
съёмки (разрыв меньше 90 сек — тот же товар). Обработанное уезжает в `_добавлено`.

Фото HEIC с iPhone через папку не читаются: включите «Настройки → Камера → Форматы →
Наиболее совместимый» или снимайте через страницу для телефона.

## Деньги и лимиты

- **Claude**: черновик — один запрос; подача — от 15 до 40 шагов робота. По умолчанию
  стоит Claude Opus 5 со средней тщательностью. Sonnet 5 дешевле, переключается в
  настройках. Счётчик расхода — над очередью.
- **OLX**: в большинстве рубрик есть лимит бесплатных объявлений, после него подача
  платная (пакеты). Робот не платит: упрётся в лимит — остановится и напишет. Пакеты
  покупаются в кабинете OLX заранее.
- Частая однотипная подача может насторожить модерацию OLX. Интервал в 5 минут и
  настоящие действия в браузере — щадящий режим, но риск ограничений аккаунта остаётся.

## Разработка

```bash
cd olx-poster
npm install
npm start                    # запуск
npm run check                # синтаксис + быстрые тесты без сети
xvfb-run -a npx electron test/smoke-page-tools.js   # «руки» робота на локальной копии формы
npm run dist                 # установщик (на Windows; в CI — .github/workflows/olx-poster.yml)
```

Данные приложения — `%APPDATA%\OLX Poster`: `settings.json`, `queue.json`, `items/<id>/`
(фото), `olx-notes.txt` (заметки робота).
