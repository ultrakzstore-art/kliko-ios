Перетащите сюда фото одного товара
или кидайте их в папку-входящие / снимайте с телефона

Отсканируйте камерой телефона. Телефон и компьютер — в одной Wi-Fi сети.

Снимаете товар → «Отправить в очередь» → следующий. Claude сразу пишет черновик, а подача идёт по расписанию.

Windows при первом запуске спросит про доступ к сети — разрешите для частных сетей.
