Перетащите сюда фото — хоть все товары разом
Claude сам разложит их по объявлениям. Или кидайте в папку-входящие / снимайте с телефона

Отсканируйте камерой телефона. Телефон и компьютер — в одной Wi-Fi сети.

Режим «Много товаров»: снимаете подряд все вещи, каждую с разных сторон, → «Отправить». Claude раскладывает фото по товарам, пишет объявления, а подача идёт по расписанию.

Windows при первом запуске спросит про доступ к сети — разрешите для частных сетей.
