# «Моё»: примерка предложений продавцов на своём — задание на будущее (1.14+)

Записано 14.10.2026 по словам владельца: «на будущее будет по типу моя машина — туда можно будет примерить диски (чел
фоткает по шаблону свою тачку), а наши технологии — свайп: такой диск или другой диск (предложения от продавцов); так же
с чехлами для смартфонов, сумками для ноутбуков и на всё, что возможно; одежда — полный рост сфоткал по шаблону, всё
готово, чел может так одеться и сразу заказать вещи». Делать после выхода 1.12 в App Store — главная фишка 1.14.

## Суть

Не «все диски», а «диски, которые подходят к МОЕЙ машине и уже стоят на ней». Лента-свайп из реальных предложений разных
продавцов, показанных на своём фото, и заказ в одно касание через безопасную сделку. Одна механика для всего: машина,
телефон, ноутбук, одежда, мебель.

## Что уже есть (основа)

- Примерочная сервера `api/tryon.php` (docs/SERVER_TRYON.md): виды person / car / room, вырезка `item_cutout` — сервер
  готов, рубильник `tryon` выключен.
- «Подойдут ли?» (TryOn/AutoFit*): совместимость дисков и шин с машиной (PCD, ET, DIA, R).
- «Поместится ли?» (TryOn/FitBox*): вещь в комнате и на столе в настоящем размере (AR).
- Студия фото (Posting/PhotoStudio*): вырезка вещи с фона на телефоне.
- 3D-обзор из 5 фото (Model3D*, Listing3D*, docs/SERVER_3D.md).
- Шаблоны размеров (14.10.2026): точные параметры у объявлений — габариты, диагональ, шины, диски, размеры одежды и
  обуви во всех системах (docs/SERVER_DIMENSIONS.md, docs/SERVER_SIZES.md). Без этих данных подбор «что подходит»
  невозможен — это фундамент.

## План по шагам

1. **Профили «моё»** (хранятся на телефоне; на сервер — только с явного согласия) — **v1 готов, см. «Статус»**:
   - «Мой гараж»: снимок машины по шаблону (сбоку, колёса видно; подсказки камеры как в 3D-съёмке), марка / модель / год
     из мастера авто, параметры колёс — из справочника (PCD, ET, DIA, штатные R).
   - «Мои устройства»: модель телефона и ноутбука (диагональ, габариты).
   - «Мой рост и мерки»: фото в полный рост по шаблону + мерки (`fit_me` сервера, rules.fit).
2. **Чип «Подходит для моего …» в ленте и поиске** — фильтр совместимости по профилю: диски и шины, чехлы, сумки,
   одежда по размеру. Дёшево и самый полезный шаг.
3. **Свайп-примерка**: стопка подходящих предложений; свайп — следующее. Быстрый показ на телефоне без сервера и денег
   (вырезанный диск в эллипс колеса на фото машины; вещь по позе тела — Vision body pose; чехол на модели телефона).
   По нажатию «Как вживую» — фотореалистичная ИИ-картинка сервером (`api/tryon.php` kind car / person) в пределах лимитов.
4. **«Заказать» прямо из примерки** — безопасная сделка (физический товар — вне оплаты Apple можно).

Порядок по пользе: диски и шины → чехлы и сумки (почти без ИИ, одна совместимость) → одежда в полный рост (дороже и
капризнее по качеству).

## Риски и правила

- Фото тела и машины — чувствительные данные: по умолчанию только на телефоне; передача ИИ — отдельное согласие с
  названием поставщика (App Review 5.1.2(i)), удаление в один шаг, политика конфиденциальности.
- Цена и скорость ИИ-картинки: не на каждый свайп — только по нажатию; быстрый показ — на телефоне.
- Качество б/у вещей с плохих фото: опора на студию (вырезка), шаблоны размеров и 3D-обзор.
- Никаких продаж цифровых услуг в обход Apple: примерка бесплатна в пределах лимитов; больше — только товаром App Store.

## Что понадобится от сервера (ultra-site)

- Структурные параметры у объявлений (уже в договорах размеров): `rim_*`, `tyre_*`, `dim_*`, диагональ, размер одежды
  и обуви во всех системах, совместимость чехлов и сумок (модель устройства).
- Отбор ленты по совместимости: `api/listings.php?fit_car=<pcd,et,dia,r>`, `fit_phone=<модель>`, `fit_laptop=<диагональ>`,
  `size=<система:значение>`.
- Примерка на своём фото: `api/tryon.php` kind car / person с фото профиля (с согласием), очередь и лимиты.
