# OLX Watcher

Телеграм-бот: присылает новые объявления по поискам пользователей через секунды после подачи
— часто раньше, чем они появятся в поиске сайта. По мотивам Lotify.

## Площадки

| | Поиск | ⚡ Турбо по номерам | Выбор кнопками |
|---|---|---|---|
| 🟣 OLX.kz | да | да | рубрика, подрубрика, город, слова, цена |
| 🚗 Kolesa.kz | да | после проверки `probe` | рубрика, город, цена (марка/модель — ссылкой) |
| 🏠 Krisha.kz | да | после проверки `probe` | рубрика, город, цена |
| 🔴 Kaspi Объявления | да, экспериментально | — | нет, только ссылкой |

Новизна на всех площадках — по номеру объявления: приходит то, чего не было на прошлой
проверке; поднятое старьё не приходит. У Kolesa, Krisha и Kaspi подробности (заголовок, цена,
фото, описание) берутся из карточки объявления — из меток для поисковиков (og, JSON-LD).
Устройство этих сайтов изнутри не проверено: перед запуском — `npm run probe -- <ссылка>`.

Тарифы — по площадке (OLX, Kolesa, Krisha, Kaspi) или «🔥 Всё сразу» (комбо: все площадки на
срок). Тестовый доступ открывает все площадки.

## Доступ

| | Тестовый — новичку на 7 дней | Платно — 7 / 14 / 30 дней | Без доступа |
|---|---|---|---|
| Проверка поиска | раз в 10 минут | раз в 30 секунд | не проверяется |
| ⚡ Турбо (раньше поиска) | — | да | — |
| Поисков | до 3 | до 20 | — |

Срок теста — `TRIAL_DAYS`. Когда тест кончился и не оплачен, поиски на паузе, бот предлагает
/access. Владельцу бота — доступ без срока.

Оплата — `/access`:
- **Telegram Stars** — счёт прямо в чате, доступ включается сам после оплаты;
- **Kaspi** — человек видит реквизиты и сумму, переводит (в комментарии — свой ID) и жмёт
  «Я оплатил»; владельцу приходит заявка с кнопками «Дать N дн» / «Нет перевода».

Продление складывается с текущим сроком. За сутки до конца теста или платного срока и
после окончания бот напоминает.
Цены, реквизиты Kaspi и лимиты — в `.env` (`STARS_PRICES`, `KASPI_PRICES`, `KASPI_DETAILS`,
`FREE_SUBS`, `PAID_SUBS`, `FREE_POLL_SEC`).

Владелец (`ADMIN_ID` или первый `/start`): `/users` — пользователи и сроки по площадкам,
`/grant <ID> <дней> [olx|kolesa|krisha|kaspi|all]` — выдать доступ вручную (по умолчанию all), `/stats` — работа сборщика и оплаты, `/turbo` — вкл/выкл турбо.

**Важно:** все пользователи ходят в OLX с одного адреса — компьютера, где запущен бот. Чем
больше подписчиков и поисков, тем выше риск, что OLX начнёт отвечать 403. Одинаковые ссылки
разных людей бот проверяет одним запросом, турбо общий на всех платных.

## Как он видит объявления раньше

Номер объявления сквозной и растёт: короткий код в ссылке — это номер в 62-ричной записи
(`…-IDr9sfK.html` = 401214632, следующее — `r9sfL` = 401214633). Бот работает двумя способами:

| | Что делает | Скорость |
|---|---|---|
| **Поиск** | открывает ваши ссылки поиска «сначала новые» | раз в 30 сек (`POLL_SEC`) |
| **Турбо** | берёт самый свежий известный номер и проверяет следующие напрямую — в обход поиска | раз в 5 сек (`TURBO_SEC`) |

Турбо ловит объявление, пока оно ещё не в поиске, в том числе на проверке. Какие из пойманных
номеров ваши, бот решает сам: слова и цена — из ссылки поиска, рубрика и город — выучивает по
тому, что этот поиск реально показывает. Если турбо что-то пропустит — поиск догонит через
полминуты. Одно объявление приходит один раз.

В уведомлении: фото, цена, город, сколько минут назад подано, параметры, начало описания,
пометки «⚡ раньше поиска», «на проверке», «бизнес-аккаунт», и две кнопки — само объявление
(ссылка с номером после `#`) и все объявления автора.

## Запуск

1. Бот в Телеграме: [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
2. Node.js 22 LTS или новее: [nodejs.org](https://nodejs.org).
3. **Windows**: двойной щелчок по `start.bat` — откроется `.env`, впишите `BOT_TOKEN`, сохраните,
   запустите `start.bat` ещё раз.
   **Linux/сервер**: `cp .env.example .env`, впишите токен, `npm install`, `npm start`.
4. Напишите боту `/start` — вы станете его владельцем (или впишите свой Telegram ID в
   `ADMIN_ID`). Остальные, кто напишет боту, — пользователи с бесплатным доступом.
5. **Новый поиск — кнопками**: `/new` (или «➕ Новый поиск») → рубрика → подрубрика → город
   → ключевые слова (или «Пропустить») → цена («до 300000», «от 100 до 250 тыс», «300к») →
   бот делает пробный поиск на OLX и показывает, что нашлось, → «Сохранить».
   Подрубрики бот берёт с самого OLX, так что список всегда актуальный.
   По-старому тоже можно: настроить поиск на olx.kz и прислать ссылку из адресной строки.

Команды: `/new` — новый поиск, `/list` — поиски с кнопками пауза/удалить, `/turbo` — вкл/выкл турбо, `/status` —
статистика и ошибки.

Бот работает, пока запущен. Чтобы круглосуточно — оставьте ПК включённым или поставьте на
недорогой VPS (любой Linux с Node 22).

## Проверка на своей машине

Устройство OLX.kz изнутри из среды разработки проверить не удалось (сайт был недоступен),
поэтому перед первым запуском стоит прогнать диагностику:

```bash
npm run probe -- "https://www.olx.kz/d/elektronika/q-hp-250/"          # что даёт поиск
npm run probe -- "https://www.olx.kz/d/kk/obyavlenie/…-IDr9sfK.html"    # карточка и 5 следующих номеров
npm run probe -- categories elektronika                                  # подрубрики для мастера /new
npm run probe -- "https://kolesa.kz/cars/toyota/camry/almaty/"           # Kolesa: выдача, карточка, следующие номера
npm run probe -- "https://krisha.kz/prodazha/kvartiry/almaty/"           # Krisha — так же
npm run probe -- "<ссылка на поиск Kaspi Объявлений>"                     # Kaspi — выдача и карточка
```

Если поиск пишет «разбор: только ссылки» или карточка — ошибка, пришлите вывод: поправлю под
то, что реально отдаёт OLX. Ссылка «все объявления автора» задаётся шаблоном `SELLER_URL` —
проверьте её на первом уведомлении.

## Риски

- Правила OLX запрещают автоматический сбор данных. Бот бережный: первая страница поиска,
  паузы между запросами, при ограничении (403/429) сам уходит на паузу до 15 минут и пишет вам.
  Турбо — это ~2 запроса в секунду; если OLX начнёт ограничивать — `/turbo` выключает его,
  или увеличьте `TURBO_SEC`, или подключите прокси (`.env`).
- Объявления «на проверке» модерация может снять — среди них бывают мошенники.
